## 安装与自检要点

### 安卓（Android 8.0 或更新版本）
1. 如通过微信扫码打开，请先点击右上角 **`···`** 选择 **「在浏览器打开」**。
2. 下载 APK 并保存到手机本地，用文件管理器点击安装（系统提示时允许当前文件管理器安装此应用）。
3. 安装完成后点击桌面图标 **“ICU 抗菌药物”**，打开应显示 **“第 17 版离线”**。

### iPhone（iOS 15.5 或更新版本）
1. 先在 App Store 安装免费的 **Scriptable**（初次下载 App 需要联网）。
2. 使用 Safari 下载 `.scriptable` 文件并保存到“文件”App 的 **“我的 iPhone”**。
3. 在“文件”App 中长按该文件 → 点 **“共享”** → 选择 **Scriptable**（如未显示点“更多”查找）。
4. 导入后在 Scriptable 中点击 **“ICU 抗菌药物 v17”** 运行即可。

### 飞行模式自检清单
安装后打开飞行模式，在 **“模拟病例”** 中核对以下三项：
- **稳定肾损害 · 美罗培南**：示例显示 `1000 mg 每 12 小时`。
